# India-General-Election-2024-Analysis-Dashboard

📌 Project Overview
An interactive Power BI dashboard designed to analyze and visualize the results of the 2024 Indian General Elections.
This project provides multi-level insights—from national trends to constituency-level performance—enabling users to explore electoral patterns, party dominance, and voting behavior across India.

🎯 Business Problem
The Indian General Election generates massive, complex datasets across states, constituencies, and parties.
However, extracting meaningful insights for decision-making, political analysis, and trend identification is challenging without a structured and interactive analytical tool.

🎯 Objective

To build an interactive dashboard for analyzing election results at multiple levels
To identify trends in alliance performance (NDA, I.N.D.I.A., Others)
To enable drill-down analysis from national to constituency level
To provide data-driven insights into voting patterns and political landscape

📊 Dashboard Features / Pages

🏠 1. Landing Page (Navigation Panel)


Centralized navigation interface for all dashboards
Enables seamless switching between different analysis views
User-friendly and intuitive design

📊 2. Overview Analysis

Displays total seats and seat share (%) for major alliances
Highlights overall election outcome at national level
Shows party-wise seat distribution within alliances

🗺️ 3. State Demographic Analysis

Interactive map-based visualization of election results by state
Shows total seats, alliance dominance, and regional patterns
Drill-down capability for deeper exploration

🏛️ 4. Political Landscape by State

State-specific analysis of alliance performance
Displays party-wise seat distribution
Includes seat share visualization (donut chart)
Helps identify regional political dominance

🧾 5. Constituency Analysis

Detailed constituency-level insights
Displays:
Winner, Runner-up, 2nd Runner-up
Total Votes & Vote Share
EVM vs Postal Votes
Total Candidates Participated

📋 6. Details Grid (Tabular View)

Complete dataset view for all constituencies
Includes:
Candidate names
Party & Alliance
EVM Votes, Postal Votes
Total Votes & Winning Margin
Useful for validation and deep analysis

📈 Key Insights

NDA secured majority with 292 seats, forming the government
I.N.D.I.A. alliance achieved 234 seats, showing strong opposition presence
Significant regional variation in alliance dominance across states
Several constituencies witnessed close contests with low winning margins
Party performance varies widely at the state level, indicating localized political influence

🛠️ Tech Stack

DAX (Data Analysis Expressions) – Calculated measures and KPIs
Data Modeling – Relationship building for cross-filtering and aggregation
